# Scope It

Short IT support practice scenes. Figure out the scope, then the next check.

This is a help-desk practice app, not a hands-on server lab. Each scene trains the same habit:

1. Scope — one person, one device, or everyone?
2. First check
3. What to try next
4. Fix, reboot, or escalate?
